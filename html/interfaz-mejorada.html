Evaluación y Rediseño de Usabilidad (UX Review)[cite: 1]

Justificación técnica de los cambios efectuados sobre la interfaz base para garantizar accesibilidad, ritmo visual y consistencia de diseño[cite: 1].

1. Jerarquía Visual[cite: 1]

Uso de títulos estructurados (H1-H3), tipografías diferenciadas y botones de acción principal[cite: 1].

2. Espaciado y Ritmo[cite: 1]

Eliminación de agrupaciones comprimidas mediante el sistema de espaciado estándar de Bootstrap (`g-4`, `p-4`, `my-5`)[cite: 1].

3. Ratio de Contraste[cite: 1]

Paleta institucional UNAB (#002b49, #e30613, #c5a059) cumpliendo normas WCAG AA de accesibilidad[cite: 1].

4. Mobile First[cite: 1]

Diseño optimizado desde 375px con controles táctiles sin desbordes horizontales de pantalla[cite: 1].
