Evaluación y Rediseño de Usabilidad (UX Review)

Justificación técnica de los cambios efectuados sobre la interfaz base para garantizar accesibilidad y ergonomía visual.

1. Jerarquía Visual

Uso de títulos estructurados (H1-H3), tipografías diferenciadas y botones primarios destacados.

2. Espaciado y Ritmo

Eliminación de elementos amontonados usando el sistema de espaciado estándar (`g-4`, `p-4`, `my-5`).

3. Ratio de Contraste

Combinación de azul marino (`#002b49`), blanco y rojo institucional para cumplir normas WCAG AA.

4. Mobile First

Diseño pensado desde 375px con controles de toque accesibles y sin scroll horizontal.
